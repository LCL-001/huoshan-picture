# F20：页面身份与上传生命周期

## 一句话
页面缓存只能属于当前登录身份，上传/编辑状态只能属于当前路由上下文。

## 怎么用
同账号从图片详情返回列表可继续浏览；退出或换账号后不复用前账号页面。编辑图片后点击“上传图片”应得到空白新增上下文，而不是继续修改旧图。

## 怎么实现
现有 PageTransition 为 HomePage、SpaceDetailPage 启用 KeepAlive。T70 计划让缓存容器跟随登录身份销毁重建，并在空间访问失败时清除旧内容；T69 计划让 AddPicturePage 随编辑对象/空间变化重新初始化，并拒绝旧请求回包。保留服务端上传接口 id=替换、无 id=新增的契约，不以按钮文案代替请求身份。

## 怎么验证
按 `docs/designs/2026-10-17-P1账户与页面状态修复计划.md` 的 T69/T70 验收；使用永久组件/请求装配回归，最终执行结果由 plan 对应条目指向。

## 已知限制
不改变 COS 图片地址本身的访问策略；缓存隔离不是服务端授权。首页分页游标及其它 P2 不在本批。
