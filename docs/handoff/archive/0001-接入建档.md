## 坑与注意事项

1. **Windows 启动**：勿用 `mvn spring-boot:run`（CreateProcess error=206），用 `java -jar target/yun-picture-base-0.0.1-SNAPSHOT.jar`
2. **本地配置**：MySQL 口令/COS 密钥/百炼 API Key 放 `backend/src/main/resources/application-local.yaml`（被 .gitignore），模板是同目录 example；application-prod/test.yaml 同样不入库
3. **测试命名约定**：需要 MySQL/Redis 的测试类以 `IntegrationTest` 结尾；`RedisStringTest` 和 `YunPictureBaseApplicationTests` 是历史 Spring 上下文测试，按名字在 CI/门禁排除；新增纯单测自动进 CI，不用改 workflow
4. **缓存键前缀**：已统一为 `huoshantuku:`（596cb8f 迁移过存量数据），不要再引入新前缀
5. **提交风格**：中文 conventional commits，一任务一 commit
6. **本机环境**：Maven 3.9.11 + JDK 21（编译目标 17），Git Bash 下 hook 可直接调 mvn
7. **前端无单测**：门禁只覆盖后端；前端以 type-check + lint 为准
