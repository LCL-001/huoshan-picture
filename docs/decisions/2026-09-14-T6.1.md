## 决定

T6.1 独立 review（规则 13，只读会话）：**有条件通过**——两条机制本体成立（本会话自建探针独立复现"缺一不可"：只挂 connector + 吐两段后静默 → 6s 无信号；完整装配 + 从不响应 → 1020ms 抛 `WebClientRequestException <- HttpTimeoutException`），门禁 68/68 实跑绿；**R1（P1，待用户拍板）**：客户端取消（空闲超时触发 / SSE 下游断开）**不关闭上游请求**（字节码根因 `Flux.cache(0)` = `replay(0).autoConnect()`，autoConnect 不因取消断开；裸 JDK `ofPublisher` + cancel 则立刻 FIN），T7/T8 上线前须三选一：接受+文档 / 换 connector spike / 写进 T8 验收；**R2（P2）** `RetryUtils.DEFAULT_RETRY_TEMPLATE` 实为 `maxAttempts(10)` + retryOn(`TransientAiException`, **`ResourceAccessException`**) + `exponentialBackoff(2s,×5,cap180s)`，阻塞路径读超时会重试，"仅 retryOn TransientAiException"与"一次超时即失败"的口径需更正；**R3（P2）** T8 拿到的是**状态码 200** 的 `WebClientResponseException` 包裹（非裸 `TimeoutException`），须沿 cause 链判超时
