| 2026-09-14 | **工具入参剥离包裹引号（T12 实测的上游形态）**：MCP 搜图工具（`searchImage`）的返回是一整个逗号拼接的字符串，Spring AI 按 JSON 序列化后外层带一对引号（线路上实测 `"https://...jpeg,https://...jpeg"`）。本次联调里模型自己把引号剥干净了（3 条 URL 全部入库成功），但工具侧剥一层更稳，故在 `HuoshanToolSupport.cleanList` 增加成对引号（`"` / `'` / 反引号，可套多层）剥离。 | 理由：把"上游返回格式"的容错放在工具侧，比指望模型每次都处理对更可靠；`cleanList` 同时服务 id / 标签 / URL，剥成对引号对三者都安全（id 与标签不可能合法地自带一对包引号）。**未做**：不按逗号拆分单个元素——URL 里的逗号是合法的，启发式拆分风险大于收益，已记为脆弱点（F12「已知限制」）。门禁 **113 例**绿。 | 生效 |
