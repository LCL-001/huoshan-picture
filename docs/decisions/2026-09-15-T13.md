## 决定

**T13 顺带项收口：删除两个"不注册的教学遗留工具"（用户拍板"两个都删"，提交 `fdbcab7`）**：`TerminalOperationTool`（73 行，`ProcessBuilder("cmd.exe","/c", <模型给的命令>)`、工作目录是用户 home）与 `ParallelSearchTool`（127 行，注释写明"DeepResearchAgent 取证阶段专用"，而本仓没有这个 agent；实质是给 `WebSearchTool` 包一层有界并发），连同 `TerminalOperationToolTest`（`@SpringBootTest` + `ls -l`、只断言非空）与 `ParallelSearchToolTest`（6 例，mock 驱动、本就在门禁里跑）共 4 个文件删除；`.githooks/pre-commit` 的排除名单同步去掉已不存在的 `TerminalOperationToolTest`。

## 理由

**删前核实零引用**：`ToolRegistration`（MyManus 的工具表）只注册 FileOperation/WebSearch/WebScraping/ResourceDownload/PDFGeneration 五个，这两个不在它里面、也不在图库助手的 `HuoshanToolFactory` 里；全仓 main+test+yaml 除自身与自身测试外零命中 ⇒ 对两个 agent 的行为**零影响**。**为什么删而不是留**：① 规则 15"不留死代码"；② `TerminalOperationTool` 是"模型可执行本机命令"的能力，删掉它让部署必办项"旧端点 `/ai/manus/chat` 未鉴权 + 该工具可用性"只剩端点鉴权本身（2026-09-14 那条已就地注明）；③ 设计文档 L98"TerminalOperationTool 维持不注册"的意图（不给模型这个能力）由"类不存在"更强地实现。**代价**：门禁示例数 143 → **137**；F12「已知限制 3」原本把 `ParallelSearchTool` 当作"有界并发先例"引用，改写成指回 git 历史与那四条并发契约。
