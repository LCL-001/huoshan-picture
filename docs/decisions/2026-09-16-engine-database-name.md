# 引擎 MySQL 数据库命名

- **日期**：2026-09-16
- **状态**：生效
- **决定**：`ai/agent` 的生产与默认 MySQL 数据库名统一为 `huoshan_ai_agent`。

## 理由

`yu-ai-agent` 是迁入前的源仓库遗留名，不再适合作为火山图库生产数据库名；同时数据库名使用下划线，避免命令行和 SQL 中反复为连字符加引号。

## 适用范围

- 引擎默认 JDBC 地址与环境变量模板；
- `ai/agent/docker-compose.yml` 及其初始化脚本；
- 首次生产部署的建库、建表命令；
- 生产环境注入的 `MYSQL_URL`。

## 不改的历史名称

历史文档中表示“原仓库名称”的 `yu-ai-agent` 保留原文；Java 包名、应用名、密码盐和停用的向量库名称不因本决定变更。

## 迁移与回滚

首次生产部署尚未创建引擎库，因此直接创建 `huoshan_ai_agent`，不做生产数据迁移。本机已有的旧开发库不自动删除。若需临时回滚，可通过 `MYSQL_URL` 显式指向旧库。
