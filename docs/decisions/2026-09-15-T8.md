## 决定

**T8-hard 循环收敛（用户拍板：T8-c 纳入本轮、`MyManusTest` 直接删、`runSummary()` 保留）**：① `BaseAgent.run()` 退役，`runStream()` 成为唯一运行入口，两套循环收敛到 `runLoop(String, AgentEventListener)`；② 新增 `agent/event` 包（`AgentEvent` 密封接口 + `AgentEventListener` + `SseAgentEventListener`）作为"事件消费者接口"；③ `step()` 由返回 `String` 改为返回 `List<AgentEvent>`，`lastStepKind` / `lastThinkText` / `lastToolNames` 三个受保护字段**删除**（原先循环靠它们旁路取分类与明细），think 文本改由 `ToolCallAgent.act()` 从自己的 `toolCallChatResponse` 取；④ 新增 `protected SseEmitter createEmitter()` 缝（与后端 `AiAssistantProxyManager.createEmitter()` 同一手法），测试由此注入记录型 emitter；⑤ 协议固化为显式契约 `SseEventProtocolContractTest`（帧级 / 循环级 / runStream 级 / 断流共 16 例）。

## 理由

**起点实测**：`run()` 全仓无生产调用方（只测试在用）⇒ 退役对生产零影响；开工基线 `ai/agent` 门禁 **118 例**。**三处有意的行为修正**（其余语义一字未改，另有真机逐帧比对佐证）：① **卡死路径不再双发 `[DONE]`**（原先发一次再 `break`、循环尾部又发一次）；② **校验失败流补 `[DONE]`**（原先发 `answer` 后直接 `complete()`，代理 `relay()` 读不到 `[DONE]` 便判"响应意外中断"、**再补一条 answer** ⇒ 用户看到两条）；③ 失败与超时改发 `error` 事件（见下一条）。**`MyManusTest` 删除**：它 `@Resource` 注入一个从不注册为 Bean 的 `MyManus`（控制器按请求新建），被门禁排除、从未真正跑过且只 `assertNotNull`（教学遗留，属 T13 清单）；删 `run()` 会让**测试模块编译失败**，故随本任务删除，等价覆盖由 `BaseAgentTest` + 契约测试承担。**`runSummary()`/metrics 保留**：当前零生产者、严格说是死代码，但协议与前端解析里都有 metrics，删掉等于缩协议；改由契约测试的测试子类钉住它的帧与位置。**门禁**：`ai/agent` 118 → **143 例**，backend 47 → **48 例**（新增 error 帧透传守护）。**负向控制实测**（三种改法各红一次）：删掉收尾 `Done` → 7 例红；帧字段 `content` 改名 `text` → 3 例红；恢复双 `[DONE]` → 循环级"恰好一个 Done"断言红（帧级被监听器的幂等保护吞掉，恰好证明两层各司其职）。**真机**（改造前 `9daa286` worktree vs 改造后 HEAD，同一句只读提问）：改造前 frames=3、改造后 frames=4（模型当轮多调了一个工具），**帧形态与字段集合逐个一致**、终止帧各恰好 1 个。
