# 2026-09-16 首次公开部署前暂时关闭助手直接写入

## 决定

用户确认按“第一阶段前 4 点”实施：

1. 完成 T27.1 的凭据与重定向加固；
2. 在确定性写确认门完成前，暂时从图库助手工具装配中摘掉 `batchEditPictures` 与 `batchUploadByUrl`；
3. 脱敏完整 Prompt、工具参数、工具结果和未知工具异常；
4. 页面文案、示例和功能讲解同步为当前真实能力。

## 边界

- 写工具类与其单元测试保留，便于后续接确定性确认门；只是模型当前看不到、调不到。
- 普通图库页面已有的批量编辑、URL 上传和管理端 AI 打标不受影响。
- 搜图工具仍可返回候选图片，但助手不能直接把候选图写入空间。
- 管理员 `visionTagger` 仍只给建议，不落库。
- 完整恢复助手写能力前，必须完成 T27.4~T27.7 的“服务端持有操作计划 + 用户显式确认 + 单次原子执行”。

## 理由

本项目当前是低流量面试项目，可以不等待 T27 全部收口再上线；但“模型自然语言判断即写入授权”不适合作为公开部署边界。临时摘掉写工具是最小、可解释、可回滚的安全收口，同时保留空间/图片/标签查询、搜图候选和看图建议等展示价值。
