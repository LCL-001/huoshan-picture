# docs/decisions/ — 决定详情（理由与证据）

本目录存放 `docs/decisions.md` 表里那些**理由与证据过长**的决定行，原文逐字保留。

## 分工

| 文件 | 放什么 |
|---|---|
| `docs/decisions.md` | **生效口径表**：日期 + 一句决定 + 详情指针 + 状态。这是"已确认的决定"的唯一权威清单 |
| `docs/decisions/`（本目录） | 该决定的完整理由、实测证据、取舍对比 |

**口径本身以 `docs/decisions.md` 表内那一行为准**；本目录只提供"为什么"。两者冲突时以表内行为准并修本目录。

## 规则（AGENTS.md「文档归属」）

- 同一事实**只允许出现在一个文件里**。
- 新增决定时：先在 `decisions.md` 追加一行（决定写成**一句话**，≤160 字），理由超过约一段就落到本目录一个文件里，表内用 `[理由与证据](decisions/<file>.md)` 链接。
- 状态列用 `生效` / `生效（有条件）` / `挂账` / `已废弃`；**`挂账` 是受限状态**——按 AGENTS.md 规则 13，review 的 P3 只有"现在修"和"判为已知限制并关闭"两类结局，不允许长期挂着。

## 命名

`<日期>-<标识>.md`，标识优先取任务号或评审编号：`2026-09-14-T6.1.md`、`2026-09-14-R5.md`、`2026-09-15-stage1.md`（档 1）；无编号的按同日序号 `topic01`、`topic02`。**纯 ASCII 文件名**。
