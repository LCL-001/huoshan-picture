# docs/decisions/ — 决定详情（理由与证据）

本目录存放 `docs/decisions.md` 表里**理由与证据过长**的决定行的完整原文。

## 分工

| 文件 | 放什么 |
|---|---|
| `docs/decisions.md` | **生效口径表**：日期 + 一句决定（≤160 字）+ 详情指针 + 状态。这是"已确认的决定"的唯一权威清单 |
| `docs/decisions/`（本目录） | 该决定的完整理由、实测证据、取舍对比（逐字保留）；`legacy-stack.md` 为接入前存量选型 |

**口径本身以 `docs/decisions.md` 表内那一行为准**；本目录只提供"为什么"。

## 规则（AGENTS.md「文档归属」）

- 同一事实**只允许出现在一个文件里**。
- **详情不可变**：文件写定后不再修改（勘误除外）——状态变化只改主表"状态"列；决定被推翻时在主表新增一行并注明"取代 <标识>"，旧行状态改"已废弃"，不删历史。表与本目录不一致时，默认本目录是历史快照、以表为准；确属本目录笔误才改本目录。
- 新增决定时：先在 `decisions.md` 追加一行（决定写成**一句话**，≤160 字），理由超过约一段就落到本目录一个文件里，表内用 `[理由与证据](decisions/<file>.md)` 链接。
- 状态词表：`生效` / `生效（有条件）` / `已收口` / `已废弃`；**禁止"挂账"**——按 AGENTS.md 规则 13，要么现在修，要么判为已知限制并关闭。

## 命名

`<日期>-<标识>.md`，标识优先取任务号或评审编号：`2026-09-14-T6.1.md`、`2026-09-14-R5.md`、`2026-09-15-stage1.md`（档 1）；无编号的按同日序号 `topic01`、`topic02`。**纯 ASCII 文件名**。
