1. 登录 → `/assistant` 空态："历史会话"侧栏 + "还没有会话，发第一条消息试试"。
2. 第 1 轮"列出我的空间"：SSE 折叠条（工具 · 查询空间列表 / "共 0 个空间"摘要 / 详情）+ Markdown 回答 + `[DONE]` 收尾；**发送成功后侧栏立即出现该会话**（标题 = 首条消息，时间 2026/9/28）。
