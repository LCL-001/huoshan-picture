## 范围与实现

方案见 `docs/designs/2026-10-17-P1账户与页面状态修复计划.md`；代码提交 `41b410b`。

- PageTransition 为整个 KeepAlive 容器设置身份代次 key，以同步 watcher 记录每次身份变化，覆盖同 tick“退出→同账号重新登录”；正常同人详情往返保留缓存。

- 独立 review 发现父 props 清空不足以销毁分享和批量编辑弹窗本地状态；本轮在原页面写集内增加清理代次，对 PictureList / BatchEditPictureModal 使用不同前缀子树 key。未改共享弹窗、用户 store 或上传页。
- package.json 仅增加 `check:private-page-cache` 命令，不新增依赖、不改锁文件。

## 不清空原 dist 的生产构建

为遵守文件删除规则，使用显式新输出目录、emptyOutDir=false，内存加载现有 Vite 配置；esbuild 大文本传输改内存 fallback，Node fs/promises 删除入口设拒绝守卫，并比较原 dist 路径与 SHA-256。此脚本仅为验收复跑，不取代项目构建系统。执行目录 frontend：

```powershell
Get-Content -Raw -Encoding UTF8 ../docs/evidence/t70-build-no-delete.mjs | node --input-type=module
```

入库证据脚本由主线程实际执行，输出：

```text
4023 modules transformed.
built in 17.90s
BUILD_RESULT chunks=2 assets=3 total=5
EXISTING_DIST_UNCHANGED=10 files
ESBUILD_IN_MEMORY_FALLBACKS=1
DELETE_ATTEMPTS=0
exit=0
```

构建仍有超过 500 kB chunk 的告警，不为此扩大修改范围。前一次 worker 尝试产物成功但守卫拦截两次删除，最终 exit=1，**未算通过**；该次不能据 Node 守卫声称 esbuild 子进程没有自行清理内部临时文件。最终守卫 0 次只代表受监控 Node 入口，不是 OS 级子进程文件审计。所有验收构建目录保留，未清理旧 dist 或缓存目录。完整一次性日志不入库，复跑命令及本文输出是持久证据。
