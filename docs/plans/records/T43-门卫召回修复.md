# T43 实施记录 — 助手范围门卫召回修复（2026-10-01）

> 依据：`docs/designs/2026-10-01-门卫召回修复设计.md`（字据 commit `182aef9`，用户批准）；第三形态同日线上复现证据见 `docs/evidence/2026-10-01-prod-confirm-gate-readonly-probe.md` 补记。

## 改动（全部在引擎 `HuoshanAssistantAgent`，其余模块零改动）

- **A1 门卫输入瘦身**：新增 `buildScopeMessages()`（包可见测试缝）——`System(SCOPE_PROMPT v2)` + 最近一个**放行轮**的助手侧上下文（以 USER 行划轮；文本截 500 字 + 该轮工具名；整轮只有固定拒绝则再往前找；新会话/全是拒绝轮则无上下文）+ 本轮消息。历史里的固定拒绝轮与无回答 USER 行一律不进输入。
- **A2 拒绝一等公民**：`step()` 拒绝路径在返回固定话术前 `rememberAssistantMessage(new AssistantMessage(OUT_OF_SCOPE_REPLY))`——消掉"孤立 USER 行"噪音，回放从"问了没答"变为"问了、给了固定拒绝"；只影响未来轮次，不补写历史。
- **A3 判定放宽 + prompt v2**：`isInScopeDecision()`——剥代码 fence 与包裹引号、大写后取**第一个** `IN_SCOPE|OUT_OF_SCOPE` token，是 IN_SCOPE 才放行，无 token 一律 fail-closed（`OUT_OF_SCOPE…IN_SCOPE` 仍拒）；`SCOPE_PROMPT` 显式举例"搜图/整理流程中的短主题补全"与"携带 URL 的导入/整理请求"两类 in-scope 形态。
- **A4 措辞单源**：能力枚举收成 `SCOPE_CAPABILITIES_EN`，`SCOPE_PROMPT` 与 `SYSTEM_PROMPT` 共用（text block `formatted()`）；中文固定话术单源 `OUT_OF_SCOPE_REPLY`（SYSTEM_PROMPT 引用同一常量）。

## 红绿与门禁

- `HuoshanAssistantAgentScopeTest` 新增 6 例：A3 首个 token 放行 / 首个 token OUT_OF_SCOPE 仍拒 / fence 与引号剥离；A1 输入三段式（拒绝轮与无回答 USER 不进输入、放行轮含工具名、长文本截断）；A2 拒绝写回记忆。
- **先红**：12 例中 5 例新断言失败/错误（旧实现：全量历史进输入、精确相等判定、拒绝不落库）→ 实现后 **12/12 绿**；既有 4 例（含 T25 三负向、非协议输出 fail-closed）不受影响。
- 引擎全量门禁 **214/214**（`OpenAiChatModelsRetryTest` 时间敏感问题已在 09-15 收口，本轮多次全量跑无随机红）；提交门禁绿（commit `97deea3`）。
- **负向控制**：红阶段即证——恢复"全量历史进门卫输入"则 A1 例红；改回精确相等则 A3 两例红；摘掉拒绝写回则 A2 例红（红/绿两轮实测）。

## 真机四项（`mimo-v2.6-flash`，本机全链路：backend 8123 `local,test` + 引擎 8124 `local` + 真 MySQL/Redis/COS；MCP 显式关闭）

探针：`docs/evidence/2026-10-01-t43-gate-probe.mjs`（冒烟账号 `smoke-t43` 专属空间，测毕两侧库清零）。

- **A（T25 原三负向仍拒）**：量子纠缠 / Java 排序 / 上海旅游三条独立会话全部 `rejected=true`（2.5s / 1.4s / 0.8s）。
- **B（短主题跟进放行）**：同会话先"帮我搜索一些日落的图片素材"（正常回答）→ 追问"自然风景"→ **放行**（模型接续查词表与图片，24.9s）——旧精确匹配下此句按名词短语判范围外，必拒。
- **C（历史污染复测）**：同会话 3 条范围外请求各被拒（A2 起拒绝轮入库）→ "列出我的空间" **放行**（`listSpaces` 被调用，正常回答）——旧实现积累 3 条拒绝轮后同句被拒。
- **D（URL 长串放行 + T27.10 同验）**："把这张图片直链导入我的空间：https://images.pexels.com/…" → **放行**，直达 `prepareUrlImportPictures` → `confirmation_required`，卡片摘要为后端生成格式（空间名可读 + 完整 URL）；未 confirm，零写入。

## 边界与已知代价

- 分类器仍是同一大模型，无数学保证；fail-closed 与 RBAC 兜底不变，最坏是多拒（现状），不会多放权限（工具仍以调用者凭据打图库 API）。
- 误放行风险面：注入诱导分类器首 token 输出 IN_SCOPE 仍可能放行——由正式助手第二层范围提示 + 工具侧凭据兜底（与 T25 口径一致）。
- prompt v2 若放宽过度（误放行增多），回滚 = 改回 prompt 常量 + 判定函数，一笔提交即回。
