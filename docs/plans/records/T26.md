# T26 — AI 助手页面范围提示与示例改写

## 立项原因

2026-09-16 用户在真实页面验收 T25 后指出，页面仍使用“调用登录态”“可读也可改”等偏实现、偏抽象的提示语，与刚收紧的助手业务范围不够一致。

## 用户确认的文案口径

用户明确选择以下四条示例：

1. `列出我的空间`
2. `看看某个空间里有哪些图片`
3. `帮我整理这些图片的标签`
4. `搜索一些图片并放入我的空间`

其余位置按本轮推荐执行：

- 顶部说明直接描述图库能力、明确修改数据需要用户主动要求、暂不支持删除；
- 空状态标题使用“想从图库里做点什么？”；
- 空状态辅助说明改为“按当前账号权限访问”，不再向普通用户暴露“登录态”等实现术语；
- 删除重复的“可读也可改”长说明；
- 输入框占位符聚焦空间、图片、标签与搜图入库。

本次只改呈现文案，不改变助手能力、工具权限、RBAC、写入确认规则或删除能力。`docs/spec.md` 关键三行口径不变。
