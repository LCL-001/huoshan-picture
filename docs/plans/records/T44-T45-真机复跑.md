## 链路

`POST /user/login` → `POST /ai/assistant/ticket` → `GET /ai/assistant/chat?...&ticket=…`（读 SSE）→ `POST /ai/assistant/operations/confirm`（只回传 operationId+chatId+digest）→ 再 `ticket` + `chat` → `GET /ai/assistant/conversations/{chatId}/messages`。
调用 `curl` 时携带 cookie jar（satoken + SESSION）并显式加 `satoken` 头；请求/响应文本与 `history.json` 原样落在临时目录（见文末残留）。

## 诚实边界

- 第 3 轮模型还调了一次 `listPictures`，其回答同时有"事实"与"现查"两条来源；"事实确实进入模型上下文"的**确定性**证据是 `chat_message` 里那行 + 单测 `MessageConverterReplayTest.keepsOperationResultFactForTheModel`（回放保留 USER 行），真机 answer 是佐证。
- 第 2 轮（"刚才那个批量编辑完成了吗？结果怎么样"）被**范围门卫**判为 out-of-scope 拒答。这是 T43 的既有行为（门卫只吃 System + 最近放行轮 + 本轮消息，过短且不带图库词的跟进容易被拒，fail-closed 方向安全），**不是** T44/T45 的缺陷；带"T44 smoke space"的第 3 轮即放行。该形态可另作门卫改进的输入。
- MCP 未启 → 每轮开头一条降级 notice（预期，T22）。助手仍能完成整理类对话。
