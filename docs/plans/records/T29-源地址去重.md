# T29 — URL 导入按源地址 + 空间判重

> 任务条目见 `docs/plan.md` T29。口径见 `docs/decisions/2026-09-18-source-url-dedupe.md`；功能讲解见 `docs/features/F3-批量抓取.md`。本记录只保存实施过程与可复跑证据。

## 放行范围（用户 2026-09-18 批准：方案 1 + 按空间）

1. `picture` 新增 `sourceUrl` 列（URL 导入/批量抓取写入来源地址，文件上传为 null）；
2. 判重改成"源地址 + 目标空间"，命中仍拒绝并沿用"图片已存在"文案；
3. 批量抓取的并行前过滤改用同一列（公共图库 = `spaceId IS NULL`）；
4. 用文件替换图片时清空旧源地址；
5. 删掉改后无人调用的 `getByUrl`（它比对的是 COS 地址，对 URL 导入永远不命中）。

## 改动

代码提交 `2052e3f`：

- `backend/sql/add_picture_source_url.sql`（新增）+ `backend/sql/create_table.sql`（同步追加）：`sourceUrl varchar(1024) NULL` + `INDEX idx_sourceUrl (sourceUrl(191))`。**刻意不建唯一索引**——逻辑删除的行会永久占住唯一索引（tag/user 已踩过），判重靠查询。
- `Picture` 加 `sourceUrl` 字段；`PictureServiceImpl`：新增 `getBySourceUrl(sourceUrl, spaceId, excludeId)`（`spaceId` 为空走 `IS NULL`；替换时排除自身；用 `getOne(wrapper,false)` 而不是 `one()`，避免同地址多行时抛异常）、`preparePicture` 写入来源地址、替换分支显式清空旧源地址、批量过滤改用 `sourceUrl + spaceId IS NULL`；`IPictureService` / 实现类删掉 `getByUrl`。
- 本地库已执行该 DDL（`mysql ... < backend/sql/add_picture_source_url.sql`，`SHOW COLUMNS` 与 `SHOW INDEX` 已回读确认）。

## 未验证 / 说明

- **prod 未执行 DDL、未部署**：`sourceUrl` 是新增列，**必须先跑 `backend/sql/add_picture_source_url.sql` 再上 jar**；顺序与命令写进 `deploy/prod-checklist.md` §2.1。漏执行的报错面是 URL 导入/批量抓取（`Unknown column 'sourceUrl'`），文件上传不受影响（不写该列）。
