# T25 — 约束助手自然语言回答范围

## 立项原因

2026-09-16 用户发现普通用户的图库助手能回答大量与图库无关的问题，并要求修复。当前边界以 `docs/spec.md` 关键三行为唯一口径，本记录只保存复现与实施过程。

## 修复前复现

使用当前源码重新构建 `ai/agent`，以 `X-User-Role: user` 启动真实 MiMo 对话；为隔离范围判断，关闭 MCP，图库 backend 不启动。三个独立会话分别提问：

1. 解释量子纠缠；
2. 编写 Java 快速排序；
3. 制定三天上海旅游计划。

结果：三题全部得到完整通用回答；助手还会先尝试调用 `listSpaces`，失败后表示不影响回答并继续作答。结论是工具权限裁剪仍在，但自然语言回答范围没有形成硬约束，并存在无关请求触发图库读取的副作用。

## 实施计划

1. 先写自动化复现测试并看到红：固定图库助手提示词必须包含范围判定、无关请求拒绝、无关请求禁止工具调用三条约束；用可控模型桩钉住无关请求不进入工具步骤。
2. 只调整图库助手提示词与必要的最小范围守卫，不改 `MyManus` 旧端点，不改工具权限装配，不新增依赖。
3. 转绿后重新启动真实模型，复跑上述三题，并增加至少一条图库内问题作正向控制。
4. 更新 `docs/features/F11-AI助手MVP.md` 的能力边界与验证方式。
