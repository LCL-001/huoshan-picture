# docs/plans/records/ — 任务实施记录

本目录存放**单个任务的实施记录**：改了什么、红绿输出、负向控制、真机证据、执行偏差。

## 为什么要拆出来

2026-09-15 复核：`docs/plan.md` 曾达 **114 KB / 231 行**，其中绝大部分是逐任务粘贴的实施记录。后果不是"文件大"，而是**同一事实在 plan.md、decisions.md、handoff 三处各存一份**——3 天里 7 处勘误（例数 138/124、flaky 方向记反、T7 漏勾、已完成任务被列成待办）**全部**源于此。拆分后 plan.md 为 **29.7 KB / 94 行**（数字随内容变化，别当常量引用），只承担索引职责。

## 规则（AGENTS.md「文档归属」）

- **plan.md 只放**：任务号 + 标题 + 文件范围 + 验收 + 一行状态 + 指向本目录的指针。
- **本目录放**：实施记录、红绿实测、负向控制、真机证据、执行偏差。
- **影响后续决策的口径**不放这里 → 放 `docs/decisions.md`（一句）+ `docs/decisions/`（详情）。
- 同一事实**只允许出现在一个文件里**。

## 命名

| 形态 | 用于 |
|---|---|
| `T15.md`、`T6.1.md`、`T3.11.md` | 任务 id（从条目行首识别） |
| `mvp-phases.md` | 无任务号的档位/推进顺序类条目 |
| `review-p3-closure.md` | review 挂账的收口条目 |
| `section-NN.md` | plan.md 里非任务的长正文小节 |

新增记录文件时请贴同一口径命名；**纯 ASCII 文件名**（AGENTS.md 规则 10）。
