## 顺带发现（3 条用户可见 + 1 条数据卫生）

1. **模型回答里的 `##` 标题会字面显示**（P2 候选，用户可见）：回答里出现 `## 🏷️ 标签词表参考`、`## ✅ 下一步操作` 这样的原文——前端自写的 Markdown 子集（T11.1）只认 `**粗体**`/`` `代码` ``/链接/`- ` 列表/`> ` 引用，**不认 `#` 标题**，于是井号原样透出。模型经常用标题，所以这条会反复出现。
2. **步骤行里 `visionTagger` 没有中文别名与摘要**（P3）：其余工具都渲染成「工具 · 查询空间列表 / 共 37 个空间」，而打标那行只有工具名本身——`assistantFormat.ts` 的别名表里没有它。
3. **登录/发送按钮在自动化下点不动，但真人可用**：Playwright 的 `getByRole`/`dom_cua` 点击登录按钮与"发 送"按钮多次超时、且浏览器**一个请求都没发**（用页面内 XHR 记录器确证），最终靠页面内 `form button[type=submit].click()` / 按钮 `.click()` 才提交。**判断为自动化工具的短板，不是产品缺陷**——人类鼠标点击在上一次会话（T24）已被验证可用，且键盘 Enter 亦未触发提交可能与 ant-design 表单配置有关，未定性。**如实记录，未当成 bug 提。**
4. **数据库里积累了历史探针数据**（数据卫生）：`yu_picture.user` 共 **415** 行，其中至少 20+ 个是前几轮会话留下的探针账号（`sec_t1_a/b/c`、`sec_t7_lock`、`sec_t7_ip1..4`、`sec_e4*`、`zcodetest`、`66666`、`5555`、`1234`～`1234567` 等）；`tag` 词表里也堆着 `T5新词1789315248519` 这类历史测试词（UI 上可见，共 21 条标签）。**"不留探针数据"这条在跨会话时没有落实**。本次我建的两个账号已当场清除（见下），但**历史遗留我没有动**——删用户是破坏性操作，需要你点头。
